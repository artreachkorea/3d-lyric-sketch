# 3D 리릭 스케치

손그림 스케치 스타일의 3D 물결 장면 위에, 내 가사 파일과 음원을 올려 큰 손글씨 가사로 재생하는 리릭 비주얼라이저입니다. Three.js 한 파일(`index.html`)로 동작합니다.

## 사용법

1. `index.html`을 브라우저로 엽니다. (GitHub Pages로 열어도 됩니다)
2. **가사 파일 (.lrc)** 버튼으로 가사를 올립니다. 화면에 끌어다 놓아도 됩니다.
3. **음원 파일** 버튼으로 음원을 올리고 **재생**을 누릅니다.

- 가사: `.lrc`(`[01:23.45] 가사` 형식) 또는 줄바꿈된 `.txt`. 타임스탬프가 없으면 곡 길이에 맞춰 균등 배치됩니다.
- 음원: MP3, M4A, WAV 등 브라우저가 재생할 수 있는 파일.

## 포함하지 않는 것

이 저장소에는 **가사와 음원이 들어 있지 않습니다.** 둘 다 사용자가 가진 파일을 브라우저 안에서만 읽으며, 어디에도 업로드되지 않습니다. `.gitignore`가 가사·음원 파일의 커밋을 막습니다.

## 구성

- 물결: 사인파로 움직이는 연필 선, 초당 10회 흔들리는 손그림 지터
- 카메라: 48초 주기 스플라인 경로 (수면 위 → 물속 → 다시 위)
- 가사: 캔버스에 그린 손글씨를 3D 평면에 얹어 카메라를 따라 떠다니게 함, 단어 단위 등장
- 오디오 반응: 소리 크기에 따라 물결 높이와 글자 크기가 변함
